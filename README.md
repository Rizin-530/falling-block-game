# BRILLIANT BLOCKS — Falling Block Game

**Play Online:** [Falling Block Gameをプレイ](https://rizin-530.github.io/falling-block-game/)

ブラウザで遊べる落ちものブロックパズルを、有料級の演出とエフェクトで作り替えたゴージャス版です。
見た目はド派手に、中身は「落ちものゲームの基本」に忠実に — ガイドライン系の標準ルールをきっちり実装しています。
Vanilla HTML / CSS / JavaScriptのみ、ビルド不要です。

## 基本ルール(ガイドライン準拠)

- 盤面 **10×20**(+上方バッファ2行)、7種類のテトリミノ(公式カラー)
- **7種1巡(7-bag)** ランダマイザ
- **SRS** 回転 + 標準 **Wall Kick**(JLSTZ / I 別テーブル)、180°回転にも対応
- **HOLD** は1ピースにつき1回まで / **NEXT 5個** / **ゴーストピース**
- **ロックディレイ 500ms**(移動・回転リセット最大15回)
- ソフトドロップは重力の **20倍**、ハードドロップ即固定
- スコアは公式倍率表: Single 100 / Double 300 / Triple 500 / Tetris 800、
  T-Spin 400〜2400(3-corner判定、Mini・キック昇格あり)、**Back-to-Back ×1.5**、
  コンボ 50点×カウント、**Perfect Clear** ボーナス、ドロップ点(ソフト1点/セル、ハード2点/セル)、全てレベル倍率
- レベルは10ライン毎に上昇(重力はガイドライン系テーブル)
- **既定はエンドレス**(詰むまで続く)。150ラインは終了ではなく通過点で、到達時に「150 LINES!」のお祝い演出が出るだけ

旧版にあった VS CPU / DEV TOOLS は落として、シングルプレイの基本に集中させました。

## 演出・エフェクト

- 宝石のように光るグラデーションブロック(ハイライト+グロー描画)
- ライン消去時のパーティクル爆発+白フラッシュ、フローティングスコア
- 「TETRIS!」「T-SPIN DOUBLE」「PERFECT CLEAR!」などのバナー演出(レインボー/ゴールド)
- ハードドロップの残像・衝撃シェイク、B2B中の盤面ゴールド発光
- 積み上がり時の危険警告(赤色パルス)、レベルアップ演出
- Web Audio合成の効果音(消去アルペジオ、TETRISファンファーレ等)、カウントダウン 3・2・1・GO!
- オーロラ+星空の背景アニメーション、ガラス質パネル
- スコアはブラウザに保存されるハイスコア

### VEGAS MODE(v2.1.0、既定ON・設定でOFF可)

- **FEVER**: ライン消去でゲージが溜まり、満タンで15秒のFEVER TIME(盤面が色相シフト発光)
- **花火**(TETRIS / T-SPIN / PERFECT CLEAR / レベルアップ)、**コイン噴水+ジャックポット音**(PERFECT CLEAR / B2B TETRIS)
- 消去ラインの**レーザースイープ**、ハードドロップの**衝撃波リング**、画面**フラッシュ+ズームパンチ+ヒットストップ**
- 背景のスポットライトビーム、ロゴのネオンフリッカー、落下ピースの残像、盤内を漂うキラキラ

### VEGAS MAX(v2.3.0追加分)

- **全画面花火・紙吹雪キャノン**: TETRIS / PERFECT CLEAR / FEVER突入 / 150ライン通過 / レベルアップで画面全体に打ち上がる
- **アトラクトモード**: スタート画面でも定期的に花火が上がる
- **スコア・カウントアップ**: スコア表示が数字を巻き上げながら増える。レベル/ライン数の変化時は数字がポップ
- **コンボ熱狂**: コンボ4以上で盤面の内側グローが炎色に
- **出現ポータル**: 新ピース出現時にリング+火花、TETRIS等のバナーは特大表示

## 操作方法(一般的な標準キーマップ)

| 操作 | キー |
|---|---|
| 左 / 右移動 | `←` / `→` |
| ソフトドロップ | `↓` |
| ハードドロップ | `Space` |
| 右回転 | `↑` / `X` |
| 左回転 | `Z` |
| 180°回転 | `A` |
| HOLD | `C` / `Shift` |
| 一時停止 / 再開 | `P` / `Esc` |
| リスタート | `R` |
| サウンド ON/OFF | `M` |

スマートフォン等では画面下のタッチボタンでも操作できます。

## Settings

- **DAS**: 左右長押しから連続移動が始まるまでの時間(既定 150ms)
- **ARR**: 連続移動の間隔(既定 30ms、0で瞬時)
- **SFX / VOLUME**: 効果音
- **VISUAL EFFECTS / SCREEN SHAKE**: 演出のON/OFF

設定とハイスコアは `localStorage` に保存され、外部送信はしません。

## 起動方法

```bash
python -m http.server 8000
# → http://localhost:8000/
```

`index.html` を直接開いても遊べます。

## テスト

```bash
node --test game.test.cjs
```

7-bag、SRS形状、Wall Kick、T-Spin判定、スコア表、重力テーブルのロジックテストです。
